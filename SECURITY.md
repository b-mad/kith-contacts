# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x (latest release) | Yes |
| Older | No |

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Include what you found, the steps to reproduce it, and the version or
commit you tested.

You can expect an acknowledgement within a week and a fix or a plan within 30 days. This is a
one-person project, so those are goals, not guarantees. We will credit you in the release notes
if you would like that.

## What is in scope

Kith Contacts runs on your own computer and listens only on that computer by default. In scope:
anything that lets a web page, another program or another user read or change contacts, bypass
the privacy lock, run code, or write files outside the app's folders. Out of scope:
attacks that already need full control of the computer or its Docker installation.

## Your own data

Never put real contact data, backups or passwords in an issue, a pull request or a report.
Use made-up examples.
